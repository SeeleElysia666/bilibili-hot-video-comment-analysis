# 热门评论情感标注规范

> 本文件说明 `data/hot_comments_clean_processed_label.csv` 中 `label` 字段的标注口径，
> 用于回答「负面、中性、正面到底怎么判」以及「边界情况怎么处理」。

## 一、标注对象

| 项目 | 说明 |
| --- | --- |
| 数据来源 | 爬虫采集的 B 站「入站必刷」热门视频热门评论 |
| 标注输入 | `data/hot_comments_clean_processed.csv`（字段：bvid、评论内容、点赞数），共 9061 条 |
| 标注单位 | **整条评论**，不拆分句子；长评论按整体倾向判断 |
| 判断依据 | 只依据**评论文本本身**，不参考点赞数、用户名、等级与 UP 主身份 |
| 判断范围 | 每条评论**独立判断**，不参考它回复的是谁、也不参考上下文 |
| 标签数量 | 每条评论**只给一个标签**（单选），必须给出，不能留空或多标签 |
| 标注方式 | 人工逐条判断情感极性，写入 `label` 字段 |
| 标注输出 | `data/hot_comments_clean_processed_label.csv` |

> 标注输入已经过正则清洗（去 URL、@用户、`[表情]`、emoji、多余空白），所以「只有表情或符号」的评论不会进入标注环节。

## 二、标签取值

| label | 含义 | 建模后类别 | 样本量 | 占比 |
| --- | --- | --- | --- | --- |
| -1 | 负面 | 0 | 1063 | 11.7% |
| 0 | 中性 | 1 | 4968 | 54.8% |
| 1 | 正面 | 2 | 3030 | 33.4% |

## 三、判定标准

判断顺序（前一步能定下来，就不再往下走）：

1. **看有没有评价对象和态度**：评论有没有明确指向的对象（作品、UP 主、平台、弹幕区、社会现象），
   并给出正向或负向的态度；
2. **按真实意图判断**：字面意思和真实意思相反时（反语、阴阳怪气），按真实意图标注；
3. **两者都不明显 → 中性**：纯打卡、纯玩梗、纯复述、纯提问都记为中性。

两条通用规则：

- **情感强度不影响标签**：同样是正面，「太赞了」和「还不错」都标 1；同样是负面，「恶心」和「有点失望」都标 -1；
- **只按这条评论自己能读出来的意思判断**：不脑补上下文，反讽也要能从这条评论本身读出来。

### 3.1 负面（label = -1）

评论整体呈现否定、批评、抱怨、讽刺或消极情绪，常见情形：

| 情形 | 示例（摘自标注数据） |
| --- | --- |
| 批评视频/作品本身 | 「和男朋友同时鉴赏的，共同得出的结论是相当的一般般。。而且团队的实力不均，感觉很奇怪」 |
| 吐槽平台现状 | 「以前看番不要钱，大量 MMD 优质鬼畜调音，现在的哔哩哔哩广告横飞……烂梗充斥着每个地方」 |
| 抱怨弹幕/评论区 | 「求求你们不要再发日期了，我屏蔽不过来，再发的话我只能屏蔽所有数字了」 |
| 借题反思社会现象、表达愤慨或悲伤 | 「看到粉发我起了一身鸡皮疙瘩，科技发展至今，文明的包容性却越来越小，网上什么都能吵起来」 |

### 3.2 中性（label = 0）

没有明显的情感倾向，或情感表达让位于玩梗与信息传递：

| 情形 | 示例 |
| --- | --- |
| 打卡、时间胶囊、蹲后续 | 「1，有没有好心的小仙女给我点个赞？以后我就在条下面打卡了」 |
| 玩梗、接龙、抖机灵 | 「天才少年老了会变成什么样？会变成天才老头」 |
| 补充信息、科普、提问 | 「粉发女生被网暴是因为营销号拿女生的照片骗人、坑人、造谣，不单单是因为染发呢」<br>「2026年来考古，有人吗」 |

### 3.3 正面（label = 1）

评论整体呈现肯定、喜爱、共鸣或祝福：

| 情形 | 示例 |
| --- | --- |
| 赞扬作品、文案、剪辑、UP 主 | 「这期视频的文案，真是看几遍也看不够的，愿称其为一种冷峻的幽默感」 |
| 表达共鸣与感动（落脚点在作品或人） | 「泪目，祝大家以后的人生都和二舅一样积极乐观，相信 up 的后代也会延续二舅的精神」 |
| 祝福、鼓励 | 「有了以前bilibili的感觉，泪目。谢谢up」 |

## 四、边界与疑难情况

| # | 情况 | 处理规则 | 标注数据中的例子 |
| --- | --- | --- | --- |
| 1 | **反话、阴阳怪气**：字面是夸，实际是骂 | 按真实意图标注 → 负面 | 「太棒啦！看了这个视频我要好好加班！决不抱怨！领导让我干嘛我干嘛！」（label = -1） |
| 2 | **「看哭了」类感动评论**：最容易分歧的一类 | 看评论的**落脚点**：落在赞扬作品/祝福他人 → 正面；落在批评网络环境、社会现象 → 负面 | 正面：「泪目，祝大家以后的人生都和二舅一样积极乐观……」（label = 1）<br>负面：「看到粉发我起了一身鸡皮疙瘩，科技发展至今，文明的包容性却越来越小……」（label = -1） |
| 3 | 玩梗 vs 真情实感 | 评论者没在表达真实评价、只是接梗 → 中性 | 「哈哈哈」「小丑」「pdd」一类的玩梗评论（label = 0） |
| 4 | 复述视频内容、补充背景信息 | 中性 | 「粉发女生被网暴是因为营销号拿女生的照片骗人、坑人、造谣……重点应该是整治肆无忌惮的营销号和网络环境。」（label = 0） |
| 5 | 一条评论里既有肯定又有否定 | 按**占主导**的倾向标注；实在判断不了记中性 | 负面：「虽然但是，我不喜欢一堆官方号在他们的视频下面蹭热度……而且也没见转发的和好好评论的，真气人」（label = -1）<br>正面：「已三连 不过发现有三处可能有问题的地方……最后希望 alan 能继续出这个系列」（label = 1） |
| 6 | 只有表情、符号、无意义内容 | 已在清洗阶段过滤，不进入标注 | — |
| 7 | 对**其他观众**喊话、呼吁弹幕礼仪 | 有明确的批评对象和否定态度 → 负面；只是倡议、说明规则 → 中性 | 负面：「求求你们不要再发日期了，我屏蔽不过来……」（label = -1）<br>中性：「请后来的同学不要发与这个无关的弹幕，真的很多填词都被删了，之前有很多精彩的填词希望大家可以去了解」（label = 0） |

## 五、标签分布与质量检查

- **类别不均衡**：中性评论 4968 条，是负面评论（1063 条）的 4.7 倍，这也是建模时对模型开启 `class_weight='balanced'` 的直接原因。
- **各标签平均字数**：负面 95 字、中性 126 字、正面 108 字，三类长度接近，说明模型的区分主要来自用词而不是文本长短。
- **标注完整性**：清洗后剩 9090 条评论，其中正则清洗后仍有内容的 9061 条**全部完成标注**，`label` 无缺失值、取值只有 -1 / 0 / 1；另外 29 条清洗后为空（只剩表情、@ 等内容）被剔除，不进入标注。

## 六、已知局限与改进方向

| 局限 | 影响 | 改进方向 |
| --- | --- | --- |
| 中性类占 54.8%，内部混杂玩梗、打卡、信息补充等不同内容 | 类内差异大，模型倾向于把所有边界样本判成中性 | 把中性拆成「玩梗类」「信息类」 |
| 负面类仅 11.7% | 各模型对负面类召回普遍偏低（0.33~0.66），最优的逻辑回归也只有 0.49 | 补充负面样本、类别加权、过采样 |
| 只记录最终标签，没有存疑标记 | 无法回溯复核 | 增加「是否存疑」列，标注时随手标记 |
| 极少数评论疑似被上游接口截断（例如 1 条 90 字的评论以「这个时代真是」结尾） | 句子不完整，只能按可见文字判断 | 采集时同时记录是否被截断，标注阶段单独标记这些样本 |

## 七、附：标注文件字段说明

| 字段 | 含义 |
| --- | --- |
| `bvid` | 评论所属视频的 BV 号，用于和视频表关联 |
| `评论内容` | 正则清洗后的评论文本，是标注时**唯一的判断依据** |
| `点赞数` | 该条评论的点赞数，只用于数据统计，不参与情感判断 |
| `label` | 人工标注的情感标签：-1 负面、0 中性、1 正面 |
